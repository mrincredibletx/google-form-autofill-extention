# Google Forms Auto-Fill Extension

Auto-fills basic details on Google Forms and prevents double filling. This extension saves you time by automatically populating common fields in Google Forms based on the settings you configure.

## Features

- Auto-fills predefined information on Google Forms.
- Helps prevent accidental double submission/filling of the same form.
- Easy to configure via the extension popup.

## How to Install the Extension

1. Clone or download this repository to your local machine.
2. Open Google Chrome.
3. In the address bar, type `chrome://extensions/` and press Enter.
4. Turn on **Developer mode** by clicking the toggle switch in the top right corner.
5. Click the **Load unpacked** button that appears in the top left corner.
6. Browse to the directory where you saved/extracted this extension (`google-form-autofill-ext`) and select the folder.
7. The extension should now appear in your list of installed extensions and its icon will be visible in the Chrome toolbar.

## How to Use

1. Click on the extension icon in your Chrome toolbar to open the settings popup.
2. Enter the basic details you want to automatically fill in Google Forms (e.g., Name, Email, etc.).
3. Save your settings.
4. Navigate to any Google Form (`docs.google.com/forms/*`).
5. The extension will automatically populate the form fields that match your configured details!
